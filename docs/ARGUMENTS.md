### **--help** или **-h**

- **Описание**: Выводит описание программы и другие аргументы, которые можно использовать
- **Примеры**:
```bash
python main.py --help
```
```bash
python main.py -h
```

### **--version** или **-v**

- **Описание**: Выводит версию программы
- **Примеры**: 
  
```bash
python main.py --version
```

```bash
python main.py -v
```

### **-t**, **--test**, **--testAuth**

- **Описание**: Проводит тестовую аутентификацию. Входные данные: Имя пользователя, пароль 
- **Примеры**:

```bash
python main.py -t
```

```bash
python main.py --test
```

```bash
python main.py --testAuth
```

### **-c**, **--charset**

- **Описание**: Символы, которые будут участвовать в подборе пароля
- **Примеры**:
  
1. Будут использованы числа от 0 до 9 в подборе
   
```bash
python main.py -c 0123456789
```

2. Будут использованы числа + латинский буквы

```bash
python main.py -c 0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ
```

### **--print-try**

- **Описание**: Принимает значение "y" или "n". Отвечает за то вывод попыток, при выборе "n" попытки будут выводиться после 250 подобранных комбинаций
- **Примеры**: 
  
```bash
python main.py --print-try n
```

```bash
python main.py --print-try y
```

### **-u**, **--user**

- **Описание**: Принимает значения имени пользовательской учётной записи
- **Пример**:

```bash
python main.py -u testUser
```

### **-l**, **--length**

- **Описание**: Задаёт длину пароля
- **Пример**:

Длина пароля у пользователя состовляет 5 символов

```bash
python main.py -l 5
```

### **-load-gif**,**--load-gif**

- **Описание**: Запускает gif файл, в нём показывается как отключить ограничитель попыток на аутентификацию в secpol.msc
- **Пример**

```bash
python main.py -load-gif
```

### **--step**, **--step-save**

- **Описание**: Принимает n числовое значение, оно будет сохранять файл, после n кол-ва попыток
- **Пример**:
  
Пользователь хочет, чтобы в файл сохранялись подобранные комбинации, после 100 попыток

```bash
python main.py --step 100
```

### **-w**, **--wordlist**

- **Описание**: Принимает в себя файл (словарь), внутри которого он будет брать значения для перебора
- **Пример**:

У человека есть файл wordlist.txt, где есть числовые комбинации и т. д.

```bash
python main.py -w wordlist.txt
```

### **--mask**

- **Описание**: Принимает строковое значение, неизвестные символы отмечаются "*"
- **Пример**

Вы знаете что у пользователя первые 5 символов слово secret, а остальные 3 символа не знаете

```bash
python main.py --mask secret***
```

### **get**

- **Описание**: Выводит что будет использоваться, чтобы узнать

```bash 
python main.py get --help
```

- **Примеры**:

1. Пользователь хочет узнать, куда подобранные попытки будут сохраняться

```bash 
python main.py get --file
```

2. Пользователь хочет узнать, с какой кодировкой будет сохраняться файл

```bash 
python main.py get --encoding
```

3. Пользователь хочет получить GIF, в случает если некорректно открывается 

```bash 
python main.py get --gif
```

### **set**

- **Описание**: Пользователь задаёт куда будет записывать попытки, чтобы узнать 

```bash 
python main.py set --help
```

- **Примеры**:

1. Пользователь хочет, чтобы файл сохранялся в кодировке utf-8

```bash
python main.py set --encoding utf-8
```

2. Пользователь хочет задать другое имя файла, в котором будут храниться подобранные попытки

```bash
python main.py set --file test.json
```

***.JSON в конце обязателен***
