[1] ОБЩАЯ ИНФОРМАЦИЯ
================================================================================

Программа проверяет пароль учётной записи Windows методом перебора (брутфорс).
Поддерживает два режима работы:
  • Генерация паролей из заданного набора символов (itertools.product)
  • Перебор по готовому списку паролей (словарь, файл)

Язык: Python 3.8+
Платформа: Только Windows (используется WinAPI через pywin32)
Лицензия: MIT
Репозиторий: https://github.com/separeit894/password_checker

⚠️  ВНИМАНИЕ: Перед запуском отключите политику блокировки учётной записи
   (secpol.msc → Локальные политики → Политики учётных записей), иначе
   учётная запись может быть заблокирована после нескольких неудачных попыток.

[2.1] 🚀 БЫСТРЫЙ СТАРТ
--------------------------------------------------------------------------------
1. Установите зависимости:
   pip install -r requirements.txt

2. Запустите программу:
   python main.py [аргументы]

3. Следуйте подсказкам в терминале.

[2.2] ⚙️ АРГУМЕНТЫ КОМАНДНОЙ СТРОКИ
--------------------------------------------------------------------------------
  -u, --user ИМЯ          Имя пользователя для проверки (обязательно)
  -c, --charset СТРОКА    Набор символов для генерации (напр. "abc123")
  -l, --length ЧИСЛО      Фиксированная длина пароля
  -w, --wordlist ФАЙЛ     Путь к файлу со списком паролей
  --print-try y|n         Показывать каждую попытку (y) или каждые 250 (n)
  --step-save ЧИСЛО       Сохранять прогресс каждые N попыток (по умолч.: 1)
  -t, --test              Тестовый режим проверки логина/пароля
  -v, --version           Показать версию программы
  --help                  Показать справку

[2.3] 📋 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
--------------------------------------------------------------------------------
• Перебор 4-значного пароля из цифр для пользователя Admin:
  python main.py -u Admin -c "0123456789" -l 4

• Перебор по словарю:
  python main.py -u Admin -w passwords.txt

• Тест аутентификации (ввод логина/пароля вручную):
  python main.py --test

• Сохранять прогресс каждые 100 попыток:
  python main.py -u Admin -c "abc" -l 3 --step-save 100

[2.5] ❓ ЧАСТЫЕ ВОПРОСЫ (FAQ)
--------------------------------------------------------------------------------
В: Программа не запускается — ошибка импорта pywin32?
О: Убедитесь, что вы в Windows и выполнили: pip install -r requirements.txt

В: Учётная запись заблокировалась?
О: Разблокируйте её вручную и отключите политику блокировки в secpol.msc.

В: Можно ли возобновить прерванный перебор?
О: Да! Программа автоматически загрузит progress.json при следующем запуске.

В: Почему не работает на Linux?
О: Программа использует WinAPI LogonUser, доступный только в Windows.

[3.2] 🔧 ЗАВИСИМОСТИ И СРЕДА
--------------------------------------------------------------------------------
• ОС: Только Windows (требуется pywin32 и доступ к WinAPI)
• Python: 3.8 или новее
• Установка: pip install -r requirements.txt

Ключевые библиотеки:
  • pywin32 / ctypes — вызов LogonUser для проверки пароля
  • itertools.product — генерация комбинаций паролей
  • mmap — эффективное чтение больших словарей
  • argparse — парсинг аргументов командной строки
  • json — работа с progress.json

[3.3] 💻 ОСНОВНЫЕ ФУНКЦИИ (main.py)
--------------------------------------------------------------------------------
• result_user_account_login(username, password) → bool
  — Вызывает LogonUser через ctypes, возвращает True при успешной аутентификации

• attempt_to_login_to_account(...) → (found, try_id, step_counter)
  — Основная логика попытки: проверка, логирование, обработка ошибок

• main()
  — Цикл перебора: itertools.product (генерация) или mmap (словарь)
  — Обработка KeyboardInterrupt → сохранение progress.json
  — Обработка исключений → вывод ошибки и пауза

[3.4] 🗃️ ФОРМАТ progress.json
--------------------------------------------------------------------------------
{
  "username": "Admin",
  "length": 4,
  "try_id": 1542,
  "tryed": ["1234", "1235", ...],
  "characters": "0123456789",
  "print_try": "y"
}

• Загружается при старте, если не переопределено аргументами
• Сохраняется каждые `step_save` попыток или при прерывании (Ctrl+C)

[3.5] 🧪 ТЕСТИРОВАНИЕ И ОТЛАДКА
--------------------------------------------------------------------------------
1. Тестовый режим аутентификации:
   python main.py --test
   → Позволяет вручную ввести логин/пароль для проверки работы LogonUser

2. Проверка аргументов:
   python main.py --help
   python main.py get --encoding
   python main.py set --encoding utf-8

3. Отладка:
   • Добавьте print() или используйте модуль logging
   • Проверьте GetLastError() при ошибке входа (код 1909 = блокировка учётки)
   • Для отладки генерации: запустите с малым charset и length
